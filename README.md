# Тестовое задание для Teaboom.ru — верстка карточки товара

Тестовое задание: Сверстать блок карточки товара интернет-магазина Teaboom.ru на HTML5, SCSS & JS.

## Запуск

```bash
git clone https://github.com/tsaminsk/teaboom-test.git
cd teaboom-test
npm install
npm run dev
```
